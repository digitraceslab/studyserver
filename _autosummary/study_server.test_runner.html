study_server.test_runner¶

Test runner that blocks real external network calls during the test suite.

PORTABILITY_SERVER_URL defaults to a real dev server (http://localhost:8001) and the AWARE db_connector talks to a MySQL instance, so an un-mocked test would silently hit them (creating/deleting real donations, opening real DB connections). This runner replaces those network seams with guards that raise immediately, so any leak fails loudly — naming the seam — instead of reaching an external service.

Tests that legitimately exercise these paths patch them locally (e.g. @patch('data_sources.models.portability_client.requests.post') or @patch('data_sources.models.portability_client.create_donation')), which overrides the guard for the duration of that test and is restored to the guard afterwards.
