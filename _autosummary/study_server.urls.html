study_server.urls¶

Top-level URL map of the study server: the site’s public API.

Every user-facing page and data endpoint is reached through these prefixes; each included app documents its own routes and their access rules.

  • / (home): front page, see users.views.home.

  • /admin/: Django admin (staff only).

  • /accounts/: users.urls (login, signup, dashboards, personal data API) and django.contrib.auth.urls (logout, password change/reset).

  • /studies/: studies.urls (study page, join/withdraw, consent workflow, legal pages, researcher data APIs).

  • /data-sources/: data_sources.urls (participants’ data sources).

  • /download/<path>/ (download_static_file): file download from STATIC_ROOT, see study_server.views.

  • /survey/: survey_extensions.urls first (disables the CSV export), then the survey library’s survey.urls.

In DEBUG, MEDIA_URL is also served from MEDIA_ROOT.
